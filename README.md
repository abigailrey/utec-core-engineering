# UTEC Core Engineering

Repositorio dedicado al desarrollo de prácticas, proyectos y fundamentos de ingeniería de software en Python, incluyendo programación orientada a objetos (POO), manejo de excepciones y estructuras de datos.

## Estructura del Proyecto
- `python_oop/`: Conceptos de programación orientada a objetos, clases y modelo de objetos.
- `python_fundamentals/`: Ejercicios de manejo de excepciones y fundamentos del lenguaje.
- `python_advanced/`: Manejo avanzado de archivos y utilidades.
